# Gym Management System User Guide

This guide is for gym owners, staff, trainers, and members.

## System Overview
The Gym Management System is a console app that helps run daily gym operations from simple menus.

You can:
- Register and log in
- Access features based on your role
- Purchase memberships
- Manage or view workout classes
- Manage or view gym merchandise

## User Roles

### Admin
- View all users and their contact details
- Delete users
- View all memberships and total annual revenue
- Manage merch inventory (add, update, delete)
- Print stock report and view total stock value

### Trainer
- Create, update, and delete workout classes
- View assigned classes
- Purchase a membership
- View available merch

### Member
- Browse workout classes
- Purchase a membership
- View available merch
- View total membership expenses

## Common Workflows

### Purchase a Membership (Trainer or Member)
1. Start the app and log in.
2. Choose Purchase Membership.
3. Select Basic, Premium, or VIP.
4. Confirm purchase.
5. The app shows the new membership ID.

### Create Workout Class (Trainer)
1. Log in as Trainer.
2. Choose Manage workout classes.
3. Choose Create class.
4. Enter class details.
5. Save.

### View Workout Classes (Member)
1. Log in as Member.
2. Choose Browse workout classes.
3. Review the listed classes.

### Manage Merchandise (Admin)
1. Log in as Admin.
2. Choose Manage merch.
3. Choose one action:
- Add merch item
- Update merch item
- Delete merch item
- Print stock report
- View total stock value

## System Limitations
- Console-only interface (no web or mobile app)
- No payment gateway integration
- Members can view merch but cannot complete checkout in this version
- Class booking and attendance tracking are not implemented
