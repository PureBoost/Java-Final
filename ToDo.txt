Project Objectives
• Develop a Java application that manages gym users, memberships, and workout
classes, and gym merchandise
• Implement user authentication and role-based access control (RBAC) for
Admins, Trainers, and Members.
• Integrate the system with a PostgreSQL database to store and manage user,
membership, workout class and merchandise data
• Demonstrate effective teamwork and project management skills using GitHub
and other tools.
Functional Requirements
User Registration and Authentication
• Users can register with a username, password, email,phonenumber,address
and role (Admin, Trainer, or Member).
• Registered users can log in and see a role-specific menu.
• Passwords must be securely stored using BCrypt hashing. Passwords can be
hashed before being saved to the Database (Maven dependency or adding JAR file
manually required to access BCrypt).
• Example classes:
o User, UserDAO, UserService
o Admin, Trainer, Member (Inheritance from User)
Product Management: Memberships, classes and
merchandise
Membership Management
• Members and trainers can purchase a gym membership.
• Admins can view and track total revenue from memberships in the gym.
• Example classes: Membership, MembershipDAO, MembershipService
Workout Class Management
• Trainers can add, update, and delete workout classes.
• Members can view a list of workout classes in the system
• Example classes: WorkoutClass, WorkoutClassDAO, WorkoutClassService
Gym Merchandise Management (Workout gear, drinks, food)
• Members can view all the products available at the gym to purchase
• Admins can add new items and set prices, print a report of all items in stock, get the
total value of their stock of merch.
• Trainers can view all the products like the Member
Role-Based Functionality
Admin
• View all users in the system, including their contact information.
• Delete users from the system.
• View all gym memberships and total annual revenue.
• Admins can add new items and set prices, print a report of all items in stock, and
get the total value of their stock of merch.
Trainer
• Create, update, and delete workout classes.
• View a list of all assigned classes.
• Purchase a gym membership for themselves.
• Trainers can view all the products like the Member
Member
• Browse workout classes.
• View their total membership expenses.
• Purchase a new gym membership.
• Members can view all the products available at the gym to purchase
Database Integration
• Use PostgreSQL to store and manage user, membership, merchandise and class
information.
• Implement CRUD operations (Create, Read, Update, Delete) for users,
memberships, merchandise, and workout classes.
• Recommended database schema can include
o Users table (userId,userName,userAddress,userPhoneNumber,userRole...)
o Memberships table
(membershipID,membershipType,membershipDescription,memberShipCos
t,memberID)
o WorkoutClasses table
(workoutClassID,workoutClasType,workoutClassDescription,trainerID (a
trainer is also a user just a different role)
o GymMerch table
( merchid,merchName,merchType,merchPrice,quantityInStock)
User Interface
• Develop a console-based user interface for interaction using a scanner.
• Provide clear menu options and navigation prompts for users.
Logging
• You must implement a logger for your application, you must use the logger in some
way, and it must write to a text file, The approach you take is up to you.
What is logging?
• Logging means recording messages from your program that describe events, data,
or errors as they happen. These messages are usually written to the console, a file,
or an external logging service.
Technical Requirements
• Programming Language: Java
• Database: PostgreSQL (If you want to try another feel free but PG is recommended)
• IDE: IntelliJ IDEA, Eclipse, VS Code, or any preferred Java IDE
• Version Control: Git/GitHub (Mandatory for submission)
• Dependency Management: Maven or Manually adding Jar files will work.
